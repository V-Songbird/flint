# Security policy

If you believe you have found a security issue in flint, please do not open a public GitHub issue.

Instead, email the details to **victor.villegas@tuta.com**.

Please include:

- A description of the issue
- Steps to reproduce it
- The file affected

You can expect an acknowledgement within 7 days.

> [!NOTE]
> flint ships no code and runs nothing on your machine. It is text you paste into your own project. The risk it carries is the risk of any instruction file: wording that steers an assistant into doing something you did not intend. That is worth reporting privately first, and it is what this policy is for.
